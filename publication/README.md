# Publication layer

Planned manuscript structure:

1. Abstract
2. Introduction
3. Molecular biology of CALR
4. Reference transcript and HGVS version reconciliation
5. Computational methods
6. Canonical and non-canonical exon 9 indel analysis
7. Diagnostic methods and limitations
8. Molecular mechanism and clinical context
9. Discussion
10. Limitations
11. Reproducibility statement
12. References

No patient-level conclusions will be included until real public data are identified, downloaded with provenance, analysed and independently checked.
