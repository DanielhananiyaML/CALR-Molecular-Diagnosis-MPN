# Evidence register

Core evidence to be incorporated into the manuscript and repository audit:

1. NCBI RefSeq: **NM_004343.4**, CALR mRNA; paired protein **NP_004334.1**.
2. ClinVar VCV000097006.16: current MANE Type 1 representation `NM_004343.4:c.1099_1150del`, legacy `NM_004343.3:c.1092_1143del52`, frameshift.
3. ClinVar VCV001028735.5: Type 2 `NM_004343.4:c.1154_1155insTTGTC`, `p.Lys385fs`, frameshift.
4. Klampfl et al. / Nangalia et al.: discovery of CALR exon 9 somatic frameshift mutations in MPNs.
5. CALR mutation-characterisation literature: Type 1, Type 2 and type-like classification.
6. Contemporary CALR-positive MPN reviews: diagnostic, prognostic and biological context.

The repository should distinguish **somatic MPN evidence** from germline ClinVar assertions. ClinVar records can contain both germline and somatic sections, so the field used must be explicit.
